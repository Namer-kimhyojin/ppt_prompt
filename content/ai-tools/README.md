# AI 업무 도구 초기 카탈로그

이 폴더는 스킬·플러그인·MCP 소개 기능(`/ai-tools/`)의 콘텐츠 원본이다. `scripts/build-ai-tools.mjs`가 정적 빌드 때 목록·상세·시작·활용법·업데이트 페이지와 사이트맵·피드 항목을 생성한다.

## 등록 기준

- 유튜브에서 도구 자체가 언급된 영상과 공식 제작자 자료를 함께 확인한다.
- 첫 조사에서는 서로 다른 채널 2개 이상에서 명시적 언급을 확인한 항목을 등록한다.
- 첫 목록 13개 중 PPTX는 참조 구현 1개와 Claude 내장 기능 1개의 스킬 계열 근거이므로 `matchScope: skill-family`로 구분했다.
- 표본은 검색으로 찾은 영상이며 유튜브 전체의 인기순위나 시장점유율을 뜻하지 않는다.
- 단순 앱·CLI 사용 영상은 같은 브랜드의 MCP가 언급된 것으로 계산하지 않는다.
- 영상 설명·챕터·제작자가 공개한 전사 등 실제 확인한 근거 범위를 기록한다.
- 공식 출처 확인과 설치·연결·실행 검증을 구분한다. 초기 레코드는 실행 미검증 상태다.

## 파일

- `{slug}.json`: 도구별 소개, 분류, 공식 출처, 이용 조건, 유튜브 근거, 검증 상태.
- `_catalog.json`: 분류별 레코드 경로, 조사 방법, 근거 영상·채널의 중복 제거 통계.
- 저장소의 `docs/research/youtube-*-2026-11-14.json`: 유형별 조사 원본.
- [조사 요약과 유형별 목록](../../docs/ai-tools-youtube-research-2026-11-14.md): 사람이 읽는 분석 문서.

## 날짜·집계 원칙

`sourceCheckedAt`은 원본 자료를 확인한 날이다. `verifiedAt`은 해당 도구를 실제 실행한 날이며, 미검증이면 null로 둔다. 원본의 게시일이 확인되지 않으면 날짜를 추정하지 않고 null로 남긴다.

영상 ID로 중복 제거하고 채널별로 한 번씩 집계한다. 같은 영상에서 여러 도구가 등장하면 각 도구의 근거에는 연결하되 전체 조사 영상 수에서는 한 번만 센다. 채널이 다르다는 사실은 계열·협찬 관계가 없다는 뜻이 아니므로 독립적인 품질평가 결과로 해석하지 않는다.

`publicationStatus: published`는 공개 페이지에 포함된다는 뜻이다. 현재 빌드는 이 값으로 항목을 거르지 않으므로, 공개하지 않을 항목은 카탈로그에서 빼야 한다. `reviewStatus: source-reviewed`는 소개 근거 확인을 뜻하며 사용 성공을 뜻하지 않는다.

관계 정보에는 아직 카탈로그에 등록하지 않은 묶음·기존 스킬도 포함될 수 있다. UI에서 내부 링크를 생성하기 전에 대상 레코드의 존재를 확인하고, 없는 항목은 이름 또는 공식 출처로 표시한다.
