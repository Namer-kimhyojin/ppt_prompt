1. 언제 사용하는 스킬인가요?

원문을 단순 요약하는 대신, 청중이 내려야 할 판단을 중심으로 발표의 순서와 각 장의 역할을 설계할 때 사용합니다. 승인·보고·설득·제안·교육·질의 대응 자료에 적용할 수 있고, 특히 여러 문서와 수치를 한 덱으로 정리해야 할 때 유용합니다.

발표 기획형전략, 배분표, 슬라이드별 메시지, 스크립트와 제작 명세
PromptDeck 이미지 생성형공통 디자인 가이드와 결합할 슬라이드별 구조화 MD
통합형검토용 발표 기획안과 이미지 생성용 MD를 분리해 함께 제공
기본 원칙: 한 슬라이드에는 결론 하나만 두고, 원문에 없는 수치·사례·출처는 만들지 않습니다. 미확정 정보는 확인 필요로 표시합니다.

7. 플랫폼별 작업 흐름

Codex판: C/V 추천안을 확정한 뒤 상세 설계

  1. 1
    원문과 요청 파악

    목적, 청중, 시간, 장수, 필수 내용과 검증된 수치를 먼저 고정합니다.

  2. 2
    발표 전략과 전체 구성

    청중의 최종 판단, 핵심 메시지 축, 예상 반론과 슬라이드 흐름을 설계합니다.

  3. 3
    배분표와 추천안 확인

    모든 슬라이드에 정보 밀도 C1~C4와 데이터 시각화 강도 V0~V4를 추천합니다.

  4. 4
    슬라이드별 상세 설계

    추천안 확인 뒤 메시지, 근거, 스크립트, 화면 큐와 제작 명세를 작성합니다.

  5. 5
    제작 경로로 인계

    Markdown 기획안, PromptDeck용 MD 또는 승인 후 실제 PPTX 제작으로 연결합니다.

중요한 확인 단계: 스킬은 상세 설계 전에 슬라이드별 C/V값과 표지·목차·간지·클로징 구현 추천을 먼저 보여줍니다. 추천안 적용 또는 03 C3/V3처럼 변경할 항목을 답해야 다음 단계로 진행됩니다.

8. PromptDeck과 함께 쓰는 방법

스킬과 PromptDeck은 같은 일을 반복하지 않습니다. 스킬이 슬라이드의 의미와 사실을 고정하고, PromptDeck이 덱 전체의 시각 언어를 제공하며, 이미지 AI가 허용 범위 안에서 최종 구도를 완성합니다.

1ppt-slide-planner논지, 표시 문구, 수치, 증거 지위, 의미 그룹과 관계를 정의
2PromptDeck덱 전체의 디자인 DNA, 색채, 타이포그래피, 형태와 프레임을 정의
3이미지 AI의미와 데이터를 지키며 구도·매체 후보를 비교해 완성 이미지를 생성
  1. 스킬에 PromptDeck 이미지 생성형 또는 통합형을 요청합니다.
  2. 슬라이드별 C/V값과 특수 슬라이드 추천안을 확인합니다.
  3. 생성된 {발표명}_promptdeck.md의 개별 슬라이드 명세를 준비합니다.
  4. PromptDeck에서 공통 디자인 가이드를 만든 뒤, 개별 슬라이드 MD와 결합해 생성합니다.

Claude판의 슬라이드 MD도 PromptDeck 작업 전 기획 입력으로 활용할 수 있습니다. 다만 PromptDeck 전용 표시·비표시 계약과 C/V값까지 자동으로 맞춘 파일이 필요하면 Codex판의 PromptDeck 이미지 생성형 또는 통합형을 선택하세요.

10. 결과를 받을 때 확인할 것

최종 점검표
  • 원문의 수치·날짜·출처·단위가 그대로 유지됐는가
  • 슬라이드 제목만 읽어도 주장과 근거가 이어지는가
  • 화면 문구와 발표자 메모가 분리됐는가
  • Codex판은 모든 장의 C/V값과 특수 페이지 구현안을 확인했는가
  • Claude판은 L1~L4 밀도와 STEP 6 내용: 표시 원칙을 지켰는가
  • 차트의 축, 범례, 기준연도, 표본과 출처가 빠지지 않았는가
  • 실제 PPTX가 필요하면 기획안 승인 후 프레젠테이션 제작 절차로 연결했는가

PDF·DOCX·PPTX·XLSX는 해당 형식을 읽고 검증할 수 있는 도구와 함께 사용합니다. HWP/HWPX를 안전하게 읽을 수 없는 환경에서는 임의로 해석하지 않고 PDF 또는 DOCX 변환본을 준비하는 것이 좋습니다.
