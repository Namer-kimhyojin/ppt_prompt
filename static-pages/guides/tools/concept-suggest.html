컨셉 제안 이용방법

막연한 이미지 아이디어를 검색 가능한 스타일 카드로 좁히고 실행할 프롬프트를 고릅니다.

컨셉 찾아보기
시작 전 준비
  • 표현할 주제 또는 대상
  • 원하는 분위기 키워드
  • 사용할 이미지 생성 엔진

언제 사용하나요?

원하는 스타일 이름을 모르거나 여러 방향을 빠르게 비교한 뒤 이미지 제작을 시작하고 싶을 때 사용합니다.

검색 팁: “세련된”보다 “공공기관 행사 포스터, 신뢰, 청색”처럼 주제와 인상을 함께 적으세요.

화면에서 따라 하기

  1. 1
    검색어 입력

    이름·태그·설명에서 찾을 주제와 스타일 키워드를 입력합니다.

  2. 2
    범주 필터

    사진, 일러스트, 그래픽 등 결과물과 가까운 범주만 남깁니다.

  3. 3
    테마와 엔진

    라이트·다크 배경과 OpenAI·Google 등 실제 사용할 생성 엔진을 선택합니다.

  4. 4
    카드 비교

    카드의 설명, 색상, 질감과 적용 예를 비교해 2~3개 후보로 줄입니다.

  5. 5
    프롬프트 복사

    선택한 카드의 프롬프트를 복사하고 주제·문구·규격을 덧붙여 외부 AI에서 실행합니다.

결과 활용

엔진별 스타일 프롬프트

복사한 스타일 문장에 실제 대상, 화면 비율, 들어갈 문구를 결합해 사용합니다.

스타일 카드 고르기

마지막 확인

  • 선택한 컨셉이 결과물의 목적과 맞는가
  • 실제 사용할 생성 엔진이 선택됐는가
  • 스타일이 제목과 정보 가독성을 해치지 않는가
  • 복사 후 주제·규격·문구를 추가했는가
