양식 이미지 이용방법

표지·간지·배경·안내판·맺음말 중 역할을 고르고 실제 문구와 시각 방향을 반영한 이미지 프롬프트를 만듭니다.

양식 이미지 시작
시작 전 준비
  • 정확한 제목·기관명·부서·날짜
  • 최종 사용 규격과 문서 분위기
  • 주최·주관·후원 등 역할 정보

먼저 이미지 역할을 고르세요

표지는 첫 장, 간지는 장 구분, 배경은 본문을 얹을 빈 화면, 안내판은 공지·방향·절차, 맺음말은 감사·Q&A 화면에 적합합니다.

화면에서 따라 하기

  1. 1
    만들 이미지 선택

    표지·간지·배경·안내판·맺음말 중 하나를 누릅니다. 다른 유형으로 바꾸면 표시 항목도 달라집니다.

  2. 2
    실제 문구 입력

    제목·부제·기관명 등을 정확히 입력하고 각 항목의 보기를 켜거나 끕니다.

  3. 3
    규격과 배치

    캔버스 비율, 제목과 메인 비주얼 위치, 역할 정보의 배치를 선택합니다. 확신이 없으면 AI 위임을 사용합니다.

  4. 4
    스타일 선택

    스타일 고르기에서 시각 방향을 고르거나 공공기관·보고서·교육자료·프리미엄 기본안을 사용합니다.

  5. 5
    프롬프트 확인

    미리보기와 표시 문구를 대조한 뒤 프롬프트 복사를 누릅니다.

결과 활용

  • 본문용 배경은 글을 올릴 빈 공간이 충분한가
