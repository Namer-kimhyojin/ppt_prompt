데이터 다이어그램 이용방법

표, 단계, 관계 데이터를 읽기 쉬운 구조로 배치하고 편집 가능한 결과로 저장합니다.

다이어그램 시작
시작 전 준비
  • 원본 수치·항목·관계
  • 한 문장 핵심 결론
  • 사용할 화면 또는 인쇄 규격

언제 사용하나요?

업무 절차, 조직 관계, 비교 수치, 일정 흐름을 보고서나 발표 자료에 넣을 때 사용합니다.

데이터 원칙: 입력 전에 원본 표의 단위와 합계를 먼저 확인하세요.

화면에서 따라 하기

  1. 1
    목적과 원본 데이터

    제목, 전달 목적, 출력 형식을 정하고 데이터를 직접 입력하거나 붙여넣습니다.

  2. 2
    도식 유형과 배치

    흐름·비교·계층·관계 중 데이터 구조에 맞는 유형과 레이아웃을 고릅니다.

  3. 3
    시각 전략

    팔레트, 그룹 구분, 연결선과 정보 밀도를 실제 사용 환경에 맞춥니다.

  4. 4
    강조와 정확성

    핵심 항목을 지정하고 숫자·단위·관계를 임의로 바꾸지 않도록 조건을 확인합니다.

  5. 5
    미리보기·내보내기

    예상 결과를 검토한 뒤 SVG·PNG·JSON 또는 이미지 생성 프롬프트로 저장합니다.

결과 활용

SVG·PNG·JSON·프롬프트

추가 편집은 SVG, 바로 삽입은 PNG, 설정 재사용은 JSON을 선택합니다.

  • 항목 사이의 방향과 관계가 정확한가
  • 범례 없이도 색상 의미를 이해할 수 있는가
  • 축소한 화면에서도 핵심 결론이 읽히는가
