공통 프롬프트 이용방법

여러 슬라이드에 반복 적용할 화면 규격과 시각 규칙을 한 번 정해 디자인 가이드로 만듭니다.

공통 프롬프트 시작
시작 전 준비
  • 발표 화면 또는 인쇄 규격
  • 원하는 분위기와 기준 색상
  • 사용 가능한 사진·아이콘·로고

언제 사용하나요?

슬라이드마다 색과 여백이 달라지는 것을 막고 싶을 때 사용합니다. 실제 제목·수치·본문은 여기에서 입력하지 않고 슬라이드 분리기에서 장별로 전달합니다.

빠르게 시작하려면: 화면 상단의 빠른 시작으로 기본값을 채운 뒤 필요한 항목만 바꾸세요.

화면에서 따라 하기

  1. 1
    출력 규격과 예약 영역

    16:9·A4 등 규격을 고르고 헤더·푸터 비율, 본문 안전 여백과 표시 항목을 정합니다.

  2. 2
    전체 시각 인상

    다음 단계를 눌러 공식성·에너지·표현 강도를 목적에 맞게 조정합니다.

  3. 3
    팔레트와 기본 배경

    기준 색상과 배경을 선택합니다. 기관 색상이 있다면 직접 색상값을 확인해 넣습니다.

  4. 4
    글자와 정보 강조

    제목·본문의 읽기 우선순위와 핵심 수치·결론의 강조 방식을 정합니다.

  5. 5
    이미지와 그래픽

    사용할 사진·아이콘·도식의 범위를 고른 뒤 디자인 가이드 생성을 누릅니다.

결과 활용

공통 디자인 가이드

디자인 가이드 복사로 복사하거나 분리기로 보내기를 눌러 장별 프롬프트 작업을 이어갑니다. 설정만 재사용하려면 JSON으로 저장하세요.

내 디자인 가이드 만들기

마지막 확인

  • 최종 사용처와 화면 비율이 맞는가
  • 헤더·푸터가 본문 공간을 지나치게 줄이지 않는가
  • 색상 대비와 글자 크기가 읽기 쉬운가
  • 실제 문구나 수치가 공통 가이드에 섞이지 않았는가
