QR코드 생성기 이용방법

주소나 정보를 실제 스캔 가능한 QR 이미지로 만들고 파일 저장 또는 라벨 인쇄까지 이어갑니다.

QR코드 만들기
시작 전 준비
  • 최종 URL 또는 담을 정보
  • 사용 크기와 배경색
  • 선택 사항: 로고 이미지

언제 사용하나요?

웹주소, Wi-Fi, 연락처, 이메일, 문자, 소셜 계정을 휴대폰 카메라로 바로 열게 할 때 사용합니다.

먼저 확인: 연결할 URL을 브라우저에서 직접 열어 정상 동작하는지 확인하세요.

화면에서 따라 하기

  1. 1
    콘텐츠 유형

    URL·Wi-Fi·연락처·이메일·SMS·소셜 중 목적에 맞는 유형을 선택합니다.

  2. 2
    데이터 입력

    주소와 필수 정보를 정확히 넣습니다. 단축 주소를 쓰면 최종 이동 주소도 확인합니다.

  3. 3
    디자인 설정

    패턴, 전경·배경색, 여백과 크기를 정하고 필요할 때만 로고를 추가합니다.

  4. 4
    QR 생성

    생성을 누른 뒤 화면 미리보기에서 패턴이 잘리지 않았는지 확인합니다.

  5. 5
    저장 또는 인쇄

    화면용은 PNG, 확대 인쇄용은 SVG로 저장하거나 라벨 출력 배치를 엽니다.

결과 활용

PNG·SVG·인쇄용 라벨

사용할 크기로 배치한 뒤 실제 기기와 인쇄본에서 각각 스캔해 보세요.
