사진 변환 프롬프터 이용방법

원본에서 유지할 인물·구조와 바꿀 스타일을 분리해 사진 편집용 지시문을 만듭니다.

변환 프롬프트 시작
시작 전 준비
  • 사용 권한이 있는 참조 사진
  • 유지할 인물·표정·구도
  • 원하는 결과 스타일과 비율

언제 사용하나요?

인물의 정체성과 원본 구도는 지키면서 일러스트, 프로필, 포스터 등 다른 표현으로 바꿀 때 사용합니다.

실행 위치: PromptDeck은 지시문을 만들며 실제 사진 편집은 외부 이미지 AI에서 진행합니다.

화면에서 따라 하기

  1. 1
    원본 구성

    사진 수, 인물 수와 단일·복수 결과 레이아웃을 실제 입력 사진에 맞춥니다.

  2. 2
    보존 조건

    얼굴 특징, 표정, 자세, 의상과 배경 중 반드시 유지할 대상을 고릅니다.

  3. 3
    결과 규격

    화면 비율, 배경 처리, 프롬프트 언어와 변환 강도를 설정합니다.

  4. 4
    스타일 갤러리

    검색과 범주 필터로 목적에 맞는 프리셋을 찾고 변환 방향을 선택합니다.

  5. 5
    프롬프트 복사·실행

    한국어 또는 영어 지시문을 복사해 원본 사진과 함께 외부 이미지 AI에 전달합니다.
