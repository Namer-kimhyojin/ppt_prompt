슬라이드 분리기 이용방법

Markdown 기획안을 읽어 슬라이드별 내용과 공통 디자인 규칙이 결합된 실행 프롬프트로 나눕니다.

슬라이드 분리기 시작
시작 전 준비
  • 슬라이드별 제목이 구분된 MD·TXT 기획안
  • 공통 프롬프트에서 만든 디자인 가이드
  • 이미지 모델에 전달할 출력 형식

기획안 형식

각 장을 제목으로 구분하고 핵심 메시지, 근거, 화면 구성을 적어 두면 가장 안정적입니다. 기획안이 없다면 ppt-slide-planner로 먼저 작성할 수 있습니다.

화면에서 따라 하기

  1. 1
    공통 프롬프트 입력

    공통 디자인 가이드를 붙여넣고 특수 슬라이드 처리와 실행 규칙을 확인합니다.

  2. 2
    기획안 입력

    MD 파일 불러오기 또는 본문 붙여넣기로 기획안을 넣습니다. 형식을 시험하려면 예시 MD 넣기를 사용하세요.

  3. 3
    분리 규칙 확인

    슬라이드 구분 규칙, 장별 본문 최대 길이, 출력 형식을 선택합니다.

  4. 4
    프롬프트 생성

    프롬프트 생성을 누르고 결과 목록의 장수와 제목이 원문과 일치하는지 확인합니다.

  5. 5
    검토·내보내기

    필요한 장은 편집 후 저장하고, 현재 장·전체 복사 또는 프롬프트 다운로드를 사용합니다.

결과 활용

장별 이미지 생성 프롬프트

각 프롬프트를 이미지 생성 모델에 한 장씩 전달합니다. 모든 장을 한 번에 넣으면 내용과 디자인 규칙이 섞일 수 있습니다.

기획안 분리하기

마지막 확인

  • 예상 장수와 생성된 장수가 같은가
  • 원문의 기관명·날짜·수치가 유지됐는가
  • 표지·목차·간지·맺음말의 전체 화면 규칙이 맞는가
  • 공통 규칙과 장별 내용이 서로 충돌하지 않는가
