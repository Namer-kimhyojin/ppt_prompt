홍보 이미지 이용방법

기존 홍보 문안을 분석하고 구성 참고도와 추천 스타일로 다듬은 뒤, 현재 프롬프트를 직접 편집해 이미지 생성에 전달합니다.

홍보 이미지 시작
시작 전 준비
  • 기존 홍보 문안 또는 핵심 메시지
  • 게시 매체와 정확한 규격
  • 필수 문구와 QR 연결 주소

언제 사용하나요?

행사 모집, 사업 안내, 캠페인 홍보처럼 문구가 정확히 보여야 하는 시각물을 기획할 때 사용합니다.

문구 입력 원칙: 날짜·장소·연락처는 최종 확정 문구로 넣으세요. 긴 한글은 이미지 안에서 직접 생성하기보다 정확한 문구 영역을 확보한 뒤 후편집하는 편이 안전합니다.

화면에서 따라 하기

  1. 1
    원문 또는 샘플로 시작

    원문으로 채우기에 기획안·홍보 문안을 붙여넣습니다. 원문이 없다면 샘플 채우기로 먼저 흐름을 확인합니다.

  2. 2
    분석 결과 검토

    찾아낸 제목·본문·CTA·규격·QR 후보를 확인합니다. 각 항목은 현재 값을 바꾸는지, 추가하는지, 꺼진 기능을 켜는지 알려줍니다.

  3. 3
    문구·매체·규격 조정

    필요한 항목만 적용한 뒤 실제 표기 문구와 게시 매체를 정합니다. A4는 21×29.7cm로, 사용자 규격은 입력한 비율대로 유지됩니다.

  4. 4
    구성 참고도·추천 스타일 확인

    결과 요약에서 문구를 누르면 바로 수정할 수 있습니다. 추천 스타일 3개를 비교해도 문구·규격·QR 설정은 유지됩니다.

  5. 5
    현재 프롬프트 편집·활용

    직접 편집한 초안은 화면 표시, 복사, 파일 저장·불러오기와 이미지 생성 전달에 똑같이 사용됩니다. 입력 설정을 반영하려면 새 설정으로 다시 만들기를 선택하고, 필요하면 실행 취소로 직전 수정본을 복구합니다.

자동 저장과 재사용: 현재 작업은 브라우저에 자동 저장됩니다. 자주 쓰는 문구·스타일·규격·수정본은 이름을 붙여 최대 20개 작업 템플릿으로 보관할 수 있습니다. 모바일에서는 입력과 결과 확인 버튼으로 화면을 전환합니다.

결과 활용

편집 가능한 홍보 이미지 생성 프롬프트

공개 웹에서는 프롬프트 복사 또는 복사 후 ChatGPT 열기를 사용합니다. 이미지 생성 탭이 있는 로컬·서버 환경에서는 현재 초안을 그 탭으로 바로 보낼 수 있습니다. 로고나 인물 사진은 사용 권리를 확인한 뒤 프롬프트와 함께 첨부하세요.
