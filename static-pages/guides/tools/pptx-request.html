PPTX 제작 요청문 이용방법

슬라이드 디자인 견본과 제작 조건을 골라, 실제로 편집 가능한 PowerPoint 파일을 요청하는 지시문을 만듭니다.

PPTX 제작 요청문 시작
시작 전 준비
  • 발표 목적과 대상
  • 원하는 화면 규격과 장수
  • 발표 원문 또는 별도 첨부 자료

언제 사용하나요?

발표 내용은 준비됐지만 디자인과 파일 제작 조건을 제작 AI에 정확히 전달하기 어려울 때 사용합니다. 이 도구는 PPTX 파일 자체가 아니라 파일 제작에 사용할 요청문을 만듭니다.

자료 전달: 원문을 화면에 붙여넣거나, 완성된 요청문과 원본 파일을 제작 AI에 함께 전달할 수 있습니다.

화면에서 따라 하기

  1. 1
    스타일 선택

    추천 스타일에서 시작하거나 분야·검색으로 전체 갤러리를 살펴보고, 발표 목적에 맞는 슬라이드 견본을 고릅니다.

  2. 2
    스타일과 색상 확인

    선택한 스타일의 특징과 팔레트를 확인합니다. 기관 색상이 필요하면 주색·강조색·바탕색을 조정합니다.

  3. 3
    제작 조건 입력

    16:9·4:3·A4 규격, 슬라이드 수, 발표 목적, 언어와 발표자 노트 포함 여부를 정합니다.

  4. 4
    발표 내용 연결

    주제·대상·원문·추가 요구사항을 선택적으로 입력합니다. 원본 자료를 따로 첨부할 때는 내용 입력을 비워도 됩니다.

  5. 5
    요청문 복사·저장

    요청문 보기를 누르고 결과를 확인한 뒤 복사하거나 TXT로 저장해 PPTX 파일을 만들 수 있는 AI에 전달합니다.

결과 활용

편집 가능한 PPTX 제작 요청문

글자·표·차트·도형을 수정 가능한 요소로 만들고, 최종 파일을 열어 넘침·깨짐·왜곡을 검수하도록 요청합니다.

마지막 확인

  • 화면 규격과 장수가 실제 발표 조건과 맞는가
  • 원문의 사실·수치·출처를 임의로 바꾸지 않도록 명시됐는가
  • 선택한 스타일이 발표 대상과 내용에 어울리는가
  • 제작 AI에 요청문과 필요한 원본 자료를 함께 전달했는가
  • 받은 PPTX를 직접 열고 편집·렌더링 상태를 확인했는가
