문서 디자인 이용방법

완성된 견본에서 출발해 실제 지면을 보며 느낌을 조정합니다. 디자인 지침과 참고 이미지를 문서 작성 AI에 함께 전달하세요.

문서 디자인 시작
시작 전 알아두세요
  • 원문 없이 디자인만 고를 수 있습니다.
  • 기본 규격은 A4 세로형 210×297mm입니다.
  • 문서 내용은 제작 AI에 별도로 전달합니다.
  • 받는 파일은 지침과 참고 이미지입니다.

언제 사용하나요?

보고서·기획 제안서·학습 교재·수험서·산문집·동화책을 만들 때 원하는 편집 디자인을 눈으로 확인하고 AI에 전달할 수 있습니다. 보고서와 기획·제안은 각각 8개, 나머지 유형은 각각 4개로 총 32개 디자인을 제공합니다. 각 디자인은 표지·본문·해당 분야의 특수 지면을 한 세트로 구성하며, 같은 유형의 견본은 동일한 예시 내용으로 비교할 수 있습니다.

핵심 원칙: 견본에 쓰인 문장과 수치는 디자인을 비교하기 위한 예시입니다. 실제 문서 내용은 별도로 제공하고, 원문을 합칠 때는 입력한 공백과 줄바꿈까지 그대로 유지합니다.

화면에서 따라 하기

  1. 1
    견본 선택

    문서 분야를 고른 뒤 디자인별 표지·본문·특수 지면을 비교합니다. 보고서와 기획·제안에서는 8개 견본을 공공·경영·현장·연구·투자·입찰·서비스 설계 등 목적에 맞춰 살펴볼 수 있습니다. 각 카드를 눌러 전체 견본을 펼치고 제목 위계, 글과 그림의 배치, 여백의 차이를 확인한 뒤 이 디자인 사용을 누르세요.

  2. 2
    보면서 조정

    본문이나 그림 페이지를 열고 색의 존재감, 여백과 호흡, 그림의 비중, 제목의 강조, 장식의 정도를 선택합니다. 지면이 바로 달라집니다. 색상·서체와 표·차트·이미지는 펼침 항목에서 세부 조정합니다.

  3. 3
    디자인 받기

    참고 이미지에 담을 페이지를 선택하고 지침 복사 또는 한 번에 받기를 누릅니다. ZIP에는 디자인 지침·설정·참고 시트·페이지 PNG·사용 안내가 들어갑니다.

같은 테마에서 배치 바꾸기

정갈한 공공 보고·선명한 데이터 보고에서는 본문·비교표·성과 차트를, 단정한 전략 기획·이미지로 설득하는 제안에서는 핵심 메시지·전략 도식·로드맵을 각각 3가지 배치로 비교할 수 있습니다. 해당 페이지를 열고 미리보기 위의 다른 배치 · 3안을 누르세요.

  1. 같은 내용·색상·규격으로 만든 배치 후보를 비교합니다.
  2. 현재 배치와 비교로 적용 전 모습을 확인하고, 크게 보기로 세부를 살펴봅니다. 여러 면으로 이어지는 견본은 면 이동 버튼으로 확인합니다.
  3. 이 배치 적용을 누르면 현재 페이지의 배치가 저장되고 디자인 지침과 참고 이미지에도 반영됩니다. 취소하거나 Escape를 누르면 기존 설정이 유지됩니다.

문서 세트 전체 보기에서는 현재 조정값이 적용된 모든 페이지 유형을 함께 볼 수 있습니다. 이 페이지 다듬기를 누르면 해당 페이지로 돌아갑니다. 전체 보기의 면수는 예시 내용으로 만든 견본의 면수이며, 실제 작성할 문서의 페이지 수를 정하는 설정은 아닙니다.

모바일에서 조정하기

선택한 분야의 디자인 카드를 위아래로 살펴보고, 카드를 눌러 한 세트씩 크게 비교하세요. 사용할 디자인을 고른 뒤 편집 화면 아래의 조정 버튼을 누릅니다. 아래에서 열린 조정창에서 느낌을 바꾸고 닫으면 적용된 지면을 넓게 볼 수 있습니다. 페이지 목록이나 이전·다음 버튼으로 다른 지면을 확인하고, 확대 버튼으로 상세 내용을 살펴보세요.

배치 선택창에서는 상단의 1·2·3 후보 버튼으로 전환해 한 장을 크게 비교합니다. 화면 아래의 적용·취소 버튼은 스크롤 중에도 사용할 수 있습니다.

규격과 서체 적용 범위

기본 규격은 A4 세로형 · 210×297 mm입니다.

문서 규격에서 A4·A3·A5·B5·Letter와 세로·가로 방향을 지정합니다. 규격을 바꾸면 해당 비율과 폭에 맞춰 지면을 다시 구성합니다. 제본·양면·맞쪽·도련은 정확한 제작 조건으로 지침에 담깁니다. 견본이나 파일 형식을 바꿔도 지정 규격은 유지됩니다.

색상·서체에서 고딕·명조 조합을 고르고 제목·본문·숫자·표·캡션·인용 중 적용할 범위를 선택합니다. 여백이나 행간은 고정 수치를 입력하지 않고 원하는 정도를 선택합니다. 실제 제작 AI는 이 느낌을 원문의 분량과 문서 용도에 맞게 해석합니다.

결과 활용

번호·기호 위계는 필요할 때만

느낌 조정 → 번호·기호 위계 → 위계 선택을 누르세요. 기본은 지정하지 않음입니다. 한글 문서형 1. → 가. → 1) → 가), 숫자 계층형, 로마 장 구분형, 기호 정리형 □ → ○ → – → ·, 번호·기호 혼합형을 견본으로 비교할 수 있습니다.

  1. 제목만 / 항목 목록만 / 제목과 항목 중 적용 범위를 고릅니다.
  2. 단계별 표식 바꾸기에서 적용할 깊이와 각 단계의 표식을 선택합니다. 위계의 느낌 조정에서 들여쓰기·강조의 정도와 표식 색상을 고를 수 있습니다.
  3. 선택 적용을 누르면 현재 견본에 있는 제목·목록과 디자인 지침에 반영됩니다. 취소하거나 Escape로 닫으면 기존 설정이 유지됩니다. 다시 지정하지 않음을 적용해 해제할 수 있습니다.

모바일에서는 하단의 견본 보기와 선택으로로 이동하세요. 원문에 없는 제목·항목은 만들지 않고, 일반 본문·표지·쪽번호·문제 번호와 참조되는 번호는 보존하도록 지침에 함께 전달합니다. 위계 설정도 자동 저장되며 내 디자인 저장함·설정 JSON·ZIP에 포함됩니다.

요소 견본으로 고르기

조정창의 요소 견본으로 고르기를 누르면 현재 세트에 있는 표·차트·이미지·도식과 서체·배경을 실제 지면으로 비교할 수 있습니다. 현재 디자인과 비교로 전후를 확인하고 선택 적용을 누르세요. 닫거나 Escape를 누르면 적용되지 않습니다.

서체는 제목·본문·숫자·표·캡션·인용의 실제 글자 견본을 보고 적용 범위를 고릅니다. 배경은 단색 면·색 띠·가는 테두리·옅은 격자를 선택한 뒤 표지·표지와 장·전체 중 적용 범위를 지정합니다. 안내 아이콘은 선형·면형·사각 배지로 통일합니다.

내용량에 따른 지면 점검

모바일에서 페이지가 작거나 일부만 보이면 견본 전체 보기를 누르세요. 설정 항목을 접고 한 장 전체를 보여 줍니다. 선택 항목 다시 보기로 비교 화면에 돌아갑니다.

미리보기 위의 분량 점검에서 짧은 글·긴 글·긴 제목·많은 표 행을 선택합니다. 다음 면으로 넘기며 문단의 흐름과 표 머리행 반복을 확인하세요. 지면을 넘는 경우 경고가 표시되므로 여백이나 규격을 다시 조정할 수 있습니다. 점검용 분량은 저장 설정·디자인 지침·다운로드 참고 이미지에 포함되지 않습니다.

내 디자인을 저장하고 재사용하기

상단이나 조정창의 내 디자인 저장함에서 이름을 입력하고 현재 디자인 저장을 누릅니다. 최대 20개를 이 브라우저에 보관합니다. 색상·서체·페이지 배치·느낌·정확한 규격·AI 해석 범위를 함께 저장하며 작성 요청은 제외합니다.

다른 브라우저로 옮기려면 현재 설정 내보내기로 JSON 파일을 받은 뒤 설정 파일 가져오기에서 확인하고 불러오세요. ZIP의 design-settings.json도 같은 방식으로 사용할 수 있습니다. 불러올 때 현재 작성 요청은 유지되고, 선택 되돌리기로 직전 디자인을 복구할 수 있습니다.

AI가 해석할 범위

조정창에서 견본에 가깝게 · 분위기를 유지하며 조정 · 폭넓게 재해석 중 하나를 선택합니다. AI가 비율·여백·장식을 변주할 범위를 디자인 지침에 전달하며, 원문과 정확한 규격·지정 색상값·서체 적용 범위는 모든 단계에서 유지하도록 안내합니다.

실제 원문 + 디자인 지침 + 참고 이미지

이 세 가지를 문서 작성 AI에 전달합니다. 이 도구가 주는 PNG는 디자인 참고용이며, DOCX·PPTX·HWPX·PDF 완성 문서는 제작 AI에서 만듭니다. 원문을 함께 복사하려면 작성 요청과 합치기를 펼치세요. ZIP에는 작성 요청 포함을 직접 선택한 경우에만 원문이 들어갑니다.
