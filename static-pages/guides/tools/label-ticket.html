용지, 명단, 연번, QR과 배경을 설정해 페이지 단위 출력 파일을 만듭니다.

라벨·티켓 시작
시작 전 준비
  • 실제 용지 규격과 칸 수
  • 연번·명단 또는 CSV
  • 선택 사항: QR·배경 이미지

언제 사용하나요?

행사 명찰, 입장권, 상품 라벨처럼 여러 데이터를 같은 규격으로 반복 인쇄할 때 사용합니다.

작업 목표: 바로 출력하려면 직접 제작, 외부 AI용 지시문이 필요하면 프롬프트 설계를 고릅니다.

화면에서 따라 하기

  1. 1
    프로젝트와 출력 규격

    품목, 용지, 앞·뒷면과 세로·가로 방향을 실제 인쇄 조건에 맞춥니다.

  2. 2
    데이터 입력·검증

    직접 입력, 붙여넣기 또는 CSV 불러오기를 사용하고 열 매핑과 누락값을 확인합니다.

  3. 3
    레이아웃 구성

    문구, 연번, 이미지와 QR의 위치·크기·정렬을 조정합니다.

  4. 4
    페이지 미리보기

    모든 페이지를 넘겨 보며 잘림, 빈 칸, 앞뒤 방향과 QR 배치를 확인합니다.

  5. 5
    저장·인쇄

    프로젝트를 저장하고 PNG·PDF 또는 인쇄를 선택합니다. 프롬프트 모드에서는 페이지·라벨별 지시문을 복사합니다.

결과 활용

프로젝트·PNG·PDF·인쇄 또는 프롬프트

인쇄 전 한 장을 시험 출력해 용지 칸과 배율을 확인한 뒤 전체 수량을 출력하세요.
