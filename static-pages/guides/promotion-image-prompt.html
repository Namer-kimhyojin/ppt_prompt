홍보 이미지 프롬프트 작성법

홍보 원문을 먼저 넣고, 분석 결과와 구성 참고도를 보며 문구·배치를 고칠 수 있습니다. 추천 스타일을 비교한 뒤 현재 초안을 직접 편집해 이미지 생성에 전달하세요.

1. PromptDeck에서는 홍보 원문부터 시작하세요

원문으로 채우기에 기존 기획안이나 홍보 문안을 붙여넣으면 제목·본문·행동 유도·규격·QR 후보를 찾아줍니다. 적용 전 검토 목록에는 각 항목이 현재 값을 바꾸는지, 비어 있는 값을 추가하는지, 꺼진 기능을 켜는지가 표시됩니다. 필요한 항목만 선택해 반영하세요. 원문이 없다면 샘플 채우기로 화면 흐름을 먼저 익힐 수 있습니다.

오른쪽 결과 요약에는 규격과 스타일, 문구 우선순위가 한글로 정리됩니다. 구성 참고도의 제목·본문·CTA를 누르면 해당 입력으로 바로 이동합니다. 내용과 매체를 바탕으로 제안되는 추천 스타일 3개는 적용 이유와 미리보기를 함께 보여주며, 스타일을 바꿔도 입력 문구·규격·QR 설정은 유지됩니다.

최종 프롬프트는 직접 편집할 수 있습니다. 편집한 현재 초안은 화면 표시, 복사, 작업 파일 저장·불러오기와 이미지 생성 전달에 동일하게 사용됩니다. 직접 편집 중에 입력 설정을 바꿔도 수정본은 덮어쓰지 않습니다. 입력 설정을 반영하려면 새 설정으로 다시 만들기를 선택하고, 필요하면 실행 취소로 직전 수정본을 복구합니다. 작업 내용은 브라우저에 자동 저장되며, 자주 쓰는 문구·스타일·규격·수정본은 이름을 붙여 최대 20개 작업 템플릿으로 보관할 수 있습니다.

화면별 활용: 공개 웹에서는 프롬프트 복사 또는 복사 후 ChatGPT 열기를 사용합니다. 이미지 생성 탭이 있는 로컬·서버 환경에서는 현재 초안을 그 탭으로 바로 보낼 수 있습니다. 모바일에서는 상단의 입력과 결과 확인 버튼으로 두 화면을 전환합니다.

2. 게시 채널과 규격부터 고정하세요

같은 내용을 담더라도 세로형 포스터, 정사각형 SNS 카드, 가로형 웹 배너의 정보 배치는 달라집니다. 프롬프트 첫 부분에 픽셀 크기 또는 화면 비율과 게시 채널을 적으세요. 모바일에서 작게 보이는 콘텐츠라면 제목과 핵심 이미지 수를 줄이고, 가장자리에는 잘림을 고려한 여백을 둡니다.

3. 메시지를 세 단계로 나누세요

홍보물은 보통 시선을 끄는 제목, 이해를 돕는 핵심 정보, 행동을 유도하는 안내로 구성됩니다. 날짜·장소·신청 대상처럼 틀리면 안 되는 정보는 별도 목록으로 고정하고, 시각 이미지가 전달할 역할을 한 문장으로 씁니다. 이미지가 문구를 반복하는 장식인지, 제품 사용 장면을 설명하는 근거인지도 구분합니다.

형식: 인스타그램 정사각형 카드, 1080×1080px
목적: 지역 창업교육 참가 신청 유도
대상: 예비창업자와 창업 3년 이내 기업
핵심 문구 영역: 상단 35%, 밝고 단순한 배경으로 비워 두기
이미지 역할: 협업 중인 성인 참가자 3명의 자연스러운 작업 장면
구성: 상단 제목 / 중앙 이미지 / 하단 일정·신청 버튼 영역
스타일: 신뢰감 있는 코발트와 민트, 평면 그래픽과 사진의 절제된 조합
금지: 이미지 안의 임의 한글, 존재하지 않는 로고, 과도한 네온, 복잡한 배경
텍스트 정확도를 높이는 방법: 생성 이미지 안에 긴 한글을 직접 넣기보다 제목·일정·연락처 영역을 비워 생성하고, 정확한 문구는 디자인 도구에서 후편집하세요.

4. 추상적인 분위기를 관찰 가능한 표현으로 바꾸세요

“세련되게”, “트렌디하게”만 적으면 결과의 기준이 모호합니다. 대신 여백 비율, 색상 수, 조명 방향, 카메라 거리, 배경 복잡도, 도형 형태처럼 확인 가능한 요소를 씁니다. 예를 들어 “밝은 자연광, 눈높이 시점, 인물은 화면 오른쪽 40%, 왼쪽은 제목용 단색 여백”처럼 설명하면 편집 가능한 구도가 나올 가능성이 높습니다.

5. 카드뉴스는 장별 역할을 먼저 설계하세요

카드뉴스 전체를 한 번에 생성하면 인물과 색상, 레이아웃이 장마다 달라질 수 있습니다. 먼저 표지, 문제 제기, 핵심 정보, 절차, 행동 유도처럼 장별 목적을 나누고 공통 스타일 규칙을 고정하세요. 인물이 반복될 때는 연령대, 복장, 헤어스타일, 촬영 톤을 공통 설명으로 유지합니다. 각 장의 문구 길이도 미리 제한하면 화면 밀도가 안정됩니다.

6. 사실과 권리를 함께 검수하세요

생성 결과에 실제 기관의 로고, 상표, 유명인 얼굴이 임의로 포함되지 않았는지 확인합니다. 직접 제공받은 사진을 쓸 때는 사용 범위와 동의를 점검하세요. 사업명, 기간, 연락처, 신청 링크는 원문과 대조하고 QR은 최종 주소로 직접 생성해 스캔 시험을 해야 합니다. 생성 이미지의 분위기가 대상에게 오해를 주거나 실제 지원 내용을 과장하지 않는지도 검토합니다.
