01

슬라이드·문서

발표와 업무 문서의 디자인 규칙을 정하고, 기획안을 장별 실행 프롬프트로 나눕니다.

슬라이드 → 공통 프롬프트

공통 프롬프트

발표 전체가 공유할 규격과 시각 규칙을 설계합니다.

세부 작업 단계

준비할 것 발표 용도, 화면 비율, 원하는 스타일

  1. 규격 · 캔버스 크기와 헤더·푸터 예약 영역을 정합니다.
  2. 인상 → 색상 → 강조 · 스타일 갤러리, 팔레트, 글자의 읽기 우선순위를 선택합니다.
  3. 자원 · 사진·아이콘·도식 등 사용할 시각 자원을 고른 뒤 디자인 가이드를 생성합니다.

결과 공통 디자인 가이드 · 복사 또는 분리기로 전달

공통 프롬프트 메뉴 열기 →
슬라이드·문서 → 문서 디자인

문서 디자인

문서 작성 요청 뒤에 붙일 구체적인 디자인·출력 지침을 만듭니다.

세부 작업 단계

준비할 것 원문 요청, 결과 형식(PPTX·DOCX·HWPX·PDF·HTML), 원하는 인상

  1. 기본 테마 · 표지·본문·데이터 미리보기 36개를 비교해 출발점을 고릅니다.
  2. 세부 정의 · 색상 8역할, 서체 크기·행간, 페이지 여백, 정보 위계, 표와 그래프 규칙을 조정합니다.
  3. 생성·전달 · 원문이 그대로 유지됐는지 확인하고 전체 프롬프트를 복사하거나 공통 프롬프트로 보냅니다.

결과 원문 요청 + 문서 디자인 지침 + 출력·검수 규칙

슬라이드 → 슬라이드 분리기

슬라이드 분리기

Markdown 기획안을 슬라이드별 프롬프트로 정리합니다.

세부 작업 단계

준비할 것 슬라이드별 기획안(MD·TXT)과 공통 디자인 가이드

  1. 공통 설정 · 디자인 가이드와 실행 규칙, 헤더·푸터 전달 범위를 확인합니다.
  2. 기획안 입력 · 파일을 불러오거나 본문을 붙여넣고 이미지 생성 준비 상태를 점검합니다.
  3. 프롬프트 생성 · 슬라이드 목록에서 각 장을 검토하고 현재 장 또는 전체를 복사합니다.

결과 장별 실행 프롬프트 · 텍스트 다운로드

  2. 표시할 데이터 · 실제 문구를 입력하고 보기 설정으로 표시 여부를 정합니다.
