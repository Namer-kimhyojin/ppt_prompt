STRUCTURE BEFORE GENERATION

AI가 그리기 전에,
검토할 수 있게 설계합니다.

PromptDeck은 발표자료·다이어그램·홍보 이미지의 막연한 요청을 목적, 필수 정보, 시각 규칙, 금지 조건이 분명한 프롬프트로 바꾸는 실무 워크스페이스입니다.

무료로 작업 시작작성법부터 보기
  • 작업 화면 광고 없음
  • 가입 없이 정적 공개 기능 사용
  • 사실·수치 검수 기준 제공
프롬프트 구조화 예시
BEFORE

성과 보고 슬라이드를 멋지게 만들어줘

목적, 수치 보존 규칙, 정보의 우선순위가 없어 결과를 검토하기 어렵습니다.

AFTER

검토 기준이 포함된 작업 명세

표현보다 먼저 바뀌면 안 되는 정보와 읽는 순서를 고정합니다.

  • 목적 · 의사결정자가 핵심 성과 파악
  • 필수 정보 · 원문 수치와 기준일 유지
  • 구성 · 결론 → 근거 → 다음 조치
  • 금지 · 임의 수치·기관명·과장 표현

설명을 위한 예시이며 실제 기관·성과를 뜻하지 않습니다.

01

도구와 콘텐츠 분리작업 앱은 /app에서 광고 없이 운영

02

원문 정보 우선바뀌면 안 되는 사실과 수치를 먼저 지정

03

사람의 최종 검수AI 결과를 그대로 납품하지 않는 흐름

WHAT YOU CAN DESIGN

결과물에 맞는 질문 순서부터 정리합니다.

입력 항목을 많이 늘리는 대신, 각 작업에서 실제로 판단해야 하는 내용을 순서대로 묻고 하나의 프롬프트로 정리합니다.

PT

발표자료와 슬라이드

청중, 슬라이드별 메시지, 공통 비주얼 규칙을 분리해 여러 장의 일관성을 설계합니다.

DG

데이터 다이어그램

표·프로세스·관계도 중 정보에 맞는 구조를 선택하고 수치 왜곡 방지 조건을 함께 둡니다.

PR

홍보 이미지

문구와 이미지의 역할, 매체 규격, 텍스트 안전 영역을 나눠 포스터와 카드뉴스를 설계합니다.

MP

지도 강조 이미지

지명·경계·도로 같은 실제 지리 구조를 보존하면서 강조 범위와 낮은 입체감을 지정합니다.

LB

라벨과 티켓

A4 용지, 여백, 재단선, 양면 인쇄 방향을 화면에서 확인하고 인쇄용 결과를 준비합니다.

QR

QR 제작

링크를 QR로 만들고 SVG·PNG 또는 라벨 인쇄 흐름으로 연결해 실제 사용 형식을 준비합니다.

REPEATABLE WORKFLOW

생성보다 먼저, 네 번의 판단을 거칩니다.

좋은 결과를 우연에 맡기지 않도록 입력과 검수 과정을 같은 순서로 반복합니다.

목적을 한 문장으로

누가 무엇을 이해하거나 결정해야 하는지 먼저 씁니다.

원문을 고정

수치, 날짜, 기관명 등 바뀌면 안 되는 정보를 구분합니다.

시각 규칙을 선택

비율, 정보 계층, 색, 이미지 역할과 금지 조건을 정합니다.

사람이 검수

사실성, 가독성, 저작권과 사용 맥락을 최종 확인합니다.

BUILT-IN STYLE REFERENCES

말로만 설명하지 않고, 스타일 기준을 비교합니다.

미리보기는 스타일 선택용 예시입니다. 실제 생성 결과는 사용하는 모델과 입력 자료에 따라 달라지며 최종 검수가 필요합니다.

PromptDeck이 대신 결정하지 않는 것

프롬프트 구조화는 검토를 돕는 과정입니다. 사실 확인과 권리 판단, 최종 품질 책임을 자동화하지 않습니다.

잘 맞는 작업

  • 반복되는 시각자료 요청을 같은 기준으로 정리
  • 수치·명칭 보존 조건과 레이아웃을 함께 전달
  • 여러 시안의 스타일 방향을 비교하고 기록

별도 확인이 필요한 작업

  • 법률·의료·재무 판단이 포함된 사실 검증
  • 타인의 상표·사진·저작물을 사용하는 권리 확인
  • 인쇄물의 실제 색상, 재단, QR 스캔 결과 확인
