작업 도구의 세 가지 상위 메뉴를 기준으로 공개 기능 11개를 정리했습니다. 메뉴명을 펼치면 준비할 입력, 세부 작업 순서, 얻을 수 있는 결과를 확인할 수 있습니다.

PC에서는 상단 작업 메뉴를, 모바일에서는 도구 → 작업군 → 세부 메뉴를 선택하세요. 아래 ‘메뉴 열기’는 해당 작업 화면으로 바로 연결됩니다. 각 안내의 단계는 작업 순서이며 별도 하위 메뉴가 없는 기능도 있습니다.

공통 프롬프트

세부 작업 단계

  2. 인상 → 색상 → 강조 · 스타일 갤러리, 팔레트, 글자의 읽기 우선순위를 선택합니다.
  3. 자원 · 사진·아이콘·도식 등 사용할 시각 자원을 고른 뒤 디자인 가이드를 생성합니다.

세부 작업 단계

  3. 프롬프트 생성 · 슬라이드 목록에서 각 장을 검토하고 현재 장 또는 전체를 복사합니다.
