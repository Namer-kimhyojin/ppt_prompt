AI 이용 및 투명성 안내

시행일: 2026년 9월 5일 · 버전 2026-09-05 · promptdeck.kr 정적 공개판

1. 현재 공개판이 하는 일

PromptDeck은 프롬프트를 설계하고 반복 작업을 줄이는 브라우저 도구입니다. 비주얼 믹서의 참조 이미지 생성은 이용자가 전송을 확인한 경우에만 PromptDeck의 동일 출처 API를 거쳐 Cloudflare Workers AI의 FLUX.1-schnell 모델을 실행합니다. API 키를 이용자에게 요구하거나 브라우저에 제공하지 않습니다. 무료 제공량 보호를 위해 이용자별·서비스 전체 일일 요청 수를 제한하며, 한도에 도달하면 생성 요청을 중단합니다. 생성 이미지는 이용자 브라우저에 저장됩니다. 그 밖의 프롬프트 작성·추천 기능은 외부 생성형 AI API를 호출하지 않습니다.

화면 표현실제 동작
“추천”, “자동 추천”, “빠른 추천”브라우저에 포함된 규칙, 점수, 프리셋과 입력 조건을 이용한 계산입니다. 외부 생성형 AI 호출이 아닙니다.
“AI 위임”PromptDeck이 지금 AI를 실행한다는 뜻이 아니라, 이용자가 나중에 프롬프트를 제출할 AI에게 해당 결정을 맡기도록 안내 문구를 넣는 선택지입니다.
Gemini·Adobe Firefly·Microsoft Designer로 열기해당 외부 사이트를 새 창으로 엽니다. PromptDeck은 프롬프트나 이미지를 자동으로 넘기지 않으며, 복사·붙여넣기와 제출은 이용자가 직접 결정합니다.

2. 미리보기 이미지와 AI 생성 표시

스타일 갤러리 등 일부 참고용 미리보기는 생성형 AI로 제작된 자산일 수 있습니다. 이는 이용자가 현재 요청해 만든 결과가 아니라 미리 포함된 예시이며, 실제 기관·인물·제품·성과를 증명하지 않습니다. 출처·생성 방식이 기록된 자산은 프로젝트의 provenance 기록으로 관리합니다.

비주얼 믹서는 생성 전에 AI 제공자와 전송 사실을 확인하고, 완료 화면에서 Cloudflare Workers AI로 생성한 이미지임을 알립니다.

3. 고영향 판단에 사용하지 않음

현재 기능은 채용, 대출, 의료, 학생 평가, 공공서비스 자격 결정 등 개인의 권리·의무에 중대한 영향을 주는 결정을 내리지 않습니다. PromptDeck의 추천은 디자인과 문서 작성의 시작점이며, 사람에 관한 평가나 전문 판단의 근거로 사용하도록 설계되지 않았습니다.

4. 외부 AI를 사용할 때의 데이터

이용자가 PromptDeck에서 만든 내용을 복사해 외부 AI 서비스에 직접 제출하면 그 시점부터 해당 제공자의 약관·개인정보 정책·보유기간·학습 이용 설정과 요금이 적용됩니다. 제출 전 다음 정보를 제거하거나 가명처리하세요.

  • 주민등록번호, 연락처, 얼굴·음성, 건강·재산 등 개인정보와 민감정보
  • 비공개 사업자료, 영업비밀, 내부 URL, 고객·임직원 정보
  • API 키, 접근 토큰, 서명된 다운로드 주소와 계정 자격증명

5. 결과 검토와 책임 있는 이용

  • 사실, 수치, 인용, 출처와 최신성을 원자료로 다시 확인합니다.
  • 법률·의료·금융·채용·안전 등 전문적 또는 고위험 판단을 AI 결과에 맡기지 않습니다.
  • 차별·편견·허위·유해 표현과 실제 인물 오인을 검토하고 수정하거나 폐기합니다.
  • 초상·상표·저작물의 사용 권한과 기존 작품과의 실질적 유사성을 확인합니다.
  • 생성형 AI 결과임을 밝혀야 하는 법령, 계약, 공모전 및 플랫폼 표시 규칙을 준수합니다.

6. 권리와 문의

외부 AI로 만든 결과에 독점권이나 저작권 성립이 자동 보장되지 않습니다. PromptDeck의 추천·프롬프트도 특정 결과, 정확성 또는 권리 비침해를 보장하지 않습니다. AI 기능·표시 또는 데이터 흐름에 관한 문의는 __PRIVACY_EMAIL__로 보낼 수 있습니다.
