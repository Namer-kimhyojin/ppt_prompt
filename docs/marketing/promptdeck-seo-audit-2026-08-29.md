# PromptDeck 무료 SEO 실행 점검

- 점검일: 2026-08-29
- 대상: `https://promptdeck.kr/`
- 원칙: 검색량을 임의 추정하지 않고 검색 의도, 현재 노출 경쟁, 사이트 기능 적합성을 기준으로 우선순위를 정함

## 요약

PromptDeck은 일반적인 “AI로 PPT 완성” 서비스보다 발표자료·다이어그램·지도·홍보물 등 시각 자료의 프롬프트와 작업 구조를 설계하는 도구에 가깝다. 따라서 광범위한 `AI PPT` 단일 키워드보다 구체적인 작업 의도가 드러나는 검색어에서 차별점을 설명하는 편이 적합하다.

이번 실행에서는 검색 가능한 실무 가이드 3종, 가이드 허브, 내부 링크, 개별 메타데이터와 Article 구조화 데이터, 사이트맵, Atom 피드, IndexNow 제출 경로를 추가했다. 검색 노출은 검색엔진의 판단에 따르며 제출만으로 보장되지 않는다.

## 검색 의도와 콘텐츠 우선순위

| 우선순위 | 검색 의도 | 대표 표현 | PromptDeck 연결 기능 | 실행 콘텐츠 |
|---|---|---|---|---|
| 높음 | 발표자료용 프롬프트를 구체화 | AI 발표자료 프롬프트, PPT 이미지 프롬프트 | 슬라이드 프롬프트 설계·분리 | 발표자료 프롬프트 가이드 |
| 높음 | 관계도·프로세스·차트를 정확히 표현 | 다이어그램 프롬프트, 데이터 시각화 프롬프트 | 데이터 다이어그램 | 데이터 다이어그램 가이드 |
| 높음 | 포스터·카드뉴스용 이미지를 기획 | 홍보 이미지 프롬프트, 포스터 AI 프롬프트 | 홍보용 이미지 생성 | 홍보 이미지 가이드 |
| 중간 | 지도·위치 안내 이미지를 설계 | 지도 이미지 프롬프트, 위치도 AI | 지도 이미지 프롬프트 | 후속 가이드 후보 |
| 중간 | 라벨·티켓·QR을 한 번에 제작 | QR 라벨 만들기, 티켓 QR 생성 | 라벨·티켓, QR 생성기 | 후속 가이드 후보 |

## 검색 결과에서 확인한 경쟁 구도

현재 한국어 검색 결과에는 Microsoft Copilot, AiPPT, Smallppt, DrawPPT처럼 완성형 발표자료 생성 서비스와 PromFit, PromBoard, Promko처럼 프롬프트 작성 보조 서비스가 함께 나타난다. PromptDeck은 “완성 파일 자동 생성”을 과장하지 않고, 여러 실무 시각 자료를 위한 구조화·검수 가능한 프롬프트 워크스페이스라는 포지션을 유지한다.

## 무료 확장 로드맵

1. 실제 사용자 질문과 유입 검색어가 확보되면 지도, 라벨·QR, 공공보고용 시각 자료 가이드를 추가한다.
2. 검색 콘솔에서 노출은 있으나 클릭이 낮은 페이지의 제목과 설명을 조정한다.
3. 기능 변경 시 관련 가이드의 예시와 검수표를 함께 갱신한다.
4. 공개 저장소 README와 GitHub 주제를 유지해 개발자·제작자 검색 접점을 확보한다.
5. 커뮤니티 게시나 디렉터리 등록은 각 서비스 규칙에 맞춰 운영자가 직접 계정으로 진행하고, 동일 문구의 반복 게시나 무관한 대량 등록은 하지 않는다.
