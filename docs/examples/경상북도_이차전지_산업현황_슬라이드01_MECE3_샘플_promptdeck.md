- 청중의 현재 인식: 기업 투자와 생산설비 규모가 지역 경쟁력의 중심이라고 이해
- 발표 후 목표 인식: 소재 생산부터 자원순환까지 이어지는 연결 구조가 경북의 차별적 경쟁력이라고 이해
- 핵심 인식 장벽: 투자 규모와 공급망 단계가 서로 분리된 정보처럼 보임
- Governing Thought: 경북은 대규모 투자와 소재·순환 공급망의 연결성을 함께 확보해 이차전지 산업 기반을 강화하고 있다.

- 다음 세션 연결: 산업 기반 확인 → 투자 집적과 정책 지원의 성과 검토

## 슬라이드 01. 소재·순환 중심축을 확보한 경북

### 양식 〔화면 표시·헤더/푸터〕

- 헤더 1단계 파트: II. 추진배경
- 헤더 2단계 제목: 1. 산업적 기반
- 헤더 3단계 부제: 가. 소재·순환 중심축 확보
- 푸터 출처: 경상북도·해솔시 이차전지 특화단지 관련 발표자료, 2023
- 푸터 주석: 투자액은 2027년까지 확정 계획 기준

### 핵심 주제·목적 〔화면 비표시〕

- 핵심 주제: 투자 집적과 공급망 연결성의 결합
- 슬라이드 목적: 대규모 투자계획이 단순한 공장 증설이 아니라 소재·순환 생태계 구축으로 이어진다는 점을 증명
- 청중 질문: 투자 규모가 지역의 지속 가능한 산업 경쟁력으로 전환되는 구조는 무엇인가?
- 인식 변화: 생산설비 중심의 규모 경쟁 → 소재 생산과 자원순환이 이어지는 구조 경쟁
- 핵심 장벽: 대표 투자지표와 공급망 단계 사이의 인과관계가 직관적으로 보이지 않음
- 목표 판단 또는 행동: 향후 정책과 기반시설 투자를 공급망 연결 강화 관점에서 검토
- 핵심 근거의 역할: 대표 투자지표는 산업 기반의 규모를 증명하고, 단계별 구조는 투자가 축적되는 경로를 설명
- 세션 연결: 산업 기반의 구조 확인 → 투자 집적이 만든 구체적 성과 검토

### 콘텐츠 〔화면 표시〕

- 핵심 문장: 경북의 차별점은 생산량보다 소재 공급망의 연결성이다
- 대표 지표: 2027년까지 해솔 기업투자 12.1조원
- 지표 설명: 2023년 경상북도 발표 기준
- 공급망 단계 1: 광물가공
- 공급망 단계 2: 전구체
- 공급망 단계 3: 양극재·음극재
- 공급망 단계 4: 리사이클링
- 구조 설명: 원료 가공에서 자원순환까지 이어지는 소재·순환 중심축

### 표현 방식 〔화면 비표시〕

- 페이지 유형: 본문·산업 기반 설명
- 정보 밀도: C2 근거까지 이해
- 데이터 시각화 강도: V1 핵심 수치 강조
- 생성 경로: 전체 슬라이드 이미지 우선
- 비주얼 논증: 대표 투자지표로 산업 기반의 규모를 먼저 각인한 뒤, 하나의 연속된 공급망이 그 규모의 구조적 의미를 설명
- 큰 레이아웃: 좌측 약 1/3은 대표 투자지표를 위한 강한 초점 영역, 우측 약 2/3는 네 단계가 끊김 없이 이어지는 수평 공급망 영역으로 구성
- 섹션 연결: 좌측 지표에서 시작한 시선이 우측 공급망의 시작점으로 자연스럽게 진입하고 마지막 순환 단계가 다시 전체 구조를 묶도록 연결
- 구도와 시선 흐름: 헤더 계층 → 대표 투자지표 → 공급망 단계 → 핵심 문장 → 출처
- 정보 위계: 1순위 대표 투자지표 → 2순위 핵심 문장 → 3순위 공급망 구조 → 4순위 기준 설명과 출처
- 핵심 강조 대상: 대표 투자지표
- 강조 설계: 산업 기반의 규모를 가장 빠르게 인식시키는 증거이므로 가장 큰 데이터 타이포그래피, 집중 여백, 공통 가이드의 강조 역할색을 활용
- 시각 언어 결합: 데이터 타이포그래피를 주 언어로 사용하고, 산업 공정을 연상시키는 연결형 인포그래픽과 절제된 기술 일러스트를 보조 언어로 결합
- 다중 레이어: 저대비 산업 맥락층, 연속 공급망 구조층, 대표 지표와 레이블 전경층을 분리해 깊이를 만들되 모든 레이어가 같은 메시지를 지원
- 개체 간격: 대표 지표 주변에는 가장 넓은 여백을 확보하고, 공급망 단계는 동일 집단으로 인식될 만큼 가깝게 두되 각 단계의 레이블이 충돌하지 않도록 균등한 호흡을 유지
- 단순 도형 탈피: 독립 카드의 반복보다 하나의 연속 경로, 재료 변화의 미세한 질감, 단계별 공정 성격이 드러나는 작은 시각 단서를 활용
- AI 조정 범위: 큰 의미 영역과 정보 위계는 유지하고 정확한 크기·간격·곡선·중첩·질감 강도는 3초 이해도와 가독성을 기준으로 최적화

### 품질 조건 〔화면 비표시〕

- 사실 고정: 양식과 콘텐츠에 정의된 문자열·수치·단위·연도만 사용하고 새로운 기업명·생산량·점유율을 추가하지 않음
- 허용 해석: 투자계획과 공급망 단계가 지역 산업 기반의 규모와 연결성을 함께 설명함
- 해석 경계: 계획된 투자액을 이미 완료된 투자 실적이나 확정된 생산성과로 표현하지 않음
- 데이터 정직성: 대표 수치의 기준연도와 목표연도를 구분하고 금액 단위를 변형하거나 환산하지 않음
- 구조 정확성: 공급망 네 단계의 순서와 명칭을 콘텐츠에 정의된 그대로 유지
- 시각 증거 지위: 기술 일러스트와 산업 질감은 일반 맥락 보조이며 특정 기업의 실제 시설이나 투자 완료를 증명하는 자료가 아님
- 가독성: 핵심 문장과 대표 수치는 발표 화면에서 즉시 읽히고, 단계 레이블과 출처는 축소 화면에서도 식별 가능해야 함
- 출력 품질: 한글·숫자·단위·연결선의 윤곽을 선명하게 유지하고 전면 블러, 과도한 글로우, 흐릿한 유리 효과를 사용하지 않음
- 렌더링 통제: 섹션 제목·필드명·Markdown 문법·작성 메모는 표시하지 않고 양식과 콘텐츠의 실제 값만 화면에 표시
