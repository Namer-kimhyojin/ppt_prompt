# 문서 디자인 실시간 작업 화면 구현 기록

기준 계획: [개발계획서](document-design-visual-workbench-development-plan-2026-09-08.md). 이 문서는 2026-09-08의 로컬 구현·검증 결과를 기록한다. 운영 배포 완료 기록이 아니다.

## 구현 범위

| 항목 | 구현 결과 |
|---|---|
| 선택 흐름 | 견본 선택 → 보면서 조정 → 디자인 받기 |
| 견본 | 보고서·기획 제안·학습 교재·수험서·산문집·동화책, 분야별 2개 디자인 |
| 지면 | 총 72개 대표 지면. 분야별로 표지·본문·비교표·차트·문제·정답·인용·펼침 등 서로 다른 구성 |
| 핵심 조정 | 색의 존재감·여백과 호흡·그림 비중·제목 강조·장식 정도 |
| 세부 조정 | 8개 색상 역할, 고딕·명조 조합과 적용 범위, 표·차트·배경·아이콘·도식·이미지 표현 |
| 정확한 규격 | A4 세로 210×297mm 기본. A3·A5·B5·Letter, 세로·가로, 제본·양면·맞쪽·도련 |
| 내보내기 | 디자인 지침, 의미 설정 JSON, 페이지 PNG, 참고 시트 PNG, ZIP. 원문은 선택한 경우에만 별도 포함 |
| 저장 | `promptdeck.documentDesign.v3` 자동 저장, 기존 35개 유형·12개 테마 명시적 이전 매핑, 기존 v1 저장본 유지 |
| 모바일 | 전체 페이지 축소 보기·확대, 하단 조정창, 이전·다음 탐색, 스크롤·포커스 복원 |
| 도움말 | 실제 데스크톱·모바일 캡처, 조작 순서와 참고 자료 전달 방법 |

## 코드 경계

- `src/document-design-bundles.js`: 12개 디자인과 지면 규칙.
- `src/document-design-samples.js`: 미리보기 전용 예시 콘텐츠.
- `src/document-design-resolver.js`: 사용자 선택을 공통 디자인과 화면용 수치로 해석.
- `src/document-design-contract-v3.js`: 원문을 보존하는 시각 편집 지침. 내부 화면 수치와 견본 콘텐츠는 제외.
- `src/document-design-renderer.js`: 실제 텍스트·표·차트·이미지 렌더링과 이어지는 페이지 분할.
- `src/document-design-migration.js`: 저장·복원·구버전 이전.
- `src/document-design-workbench.js`: 선택·조정·모바일·결과 화면.
- `src/document-design-export.js`: 상태를 고정한 뒤 독립 iframe에서 순차 캡처. 취소·실패 시 정리.

기존 문서 디자인 모듈은 호환 경로로 유지한다. 새 작업 화면이 정상 초기화되면 기존 UI의 중복 초기화를 중단한다. 탭 프록시 ID와 공통 프롬프트 전달 형식은 유지한다.

## 자산과 성능

- 사진 2개, 동화 삽화 2개를 생성해 로컬 자산으로 포함했다. 예시 용도이며 실제 문서 내용으로 전달하지 않는다.
- Noto Sans KR·Noto Serif KR은 로컬 WOFF2로 제공하고 SIL OFL 전문을 포함했다.
- Bootstrap Icons와 html2canvas는 버전을 고정하고 원본 라이선스를 포함했다.
- 문서 디자인 탭을 열기 전에는 문서 견본 사진·서체를 요청하지 않는다.
- 내보내기는 전체 앱을 복제하지 않고 필요한 지면·스타일·서체만 별도 iframe에서 처리한다.
- `npm run document-design:workbench:previews`로 동일 렌더러에서 12개 참고 시트와 3개 가이드 캡처를 생성한다. 결과와 입력 소스 해시는 `assets/document-design-workbench-previews/manifest.json`에 기록한다.

## 검증 항목

- 72개 지면의 실제 DOM, 한글 서체, 크기와 넘침 검사.
- 6개 분야에서 핵심 느낌 5개의 실제 화면 요소 변화 검사.
- 12개 세트 × 5개 용지 × 2개 방향 × 복잡한 지면 2종 = 240개 원본을 강한 제목·넉넉한 여백·높은 그림 비중으로 검사. 362개 이어지는 면에서 허용 오차를 넘는 잘림 없음.
- 긴 본문·표의 내용 보존과 머리행 반복 검사.
- 원문 공백·줄바꿈 보존, 예시 내용과 원문이 디자인 전용 내보내기에 섞이지 않는지 검사.
- 모든 기존 유형·테마의 이전 매핑, 잘못된 JSON·저장 실패 처리 검사.
- 375·390·844 가로·1440 폭에서 조작·상태 복원·다운로드 검사.
- 다크모드 1440·390 폭의 3단계 화면에서 대비·조작부 글자 크기·가로 넘침 검사.
- 실제 PNG 파일 시그니처·해상도, ZIP 내부 파일, 선형·도넛 차트 보존, 저장 중 상태 변경·취소·자산 실패 시 정리 검사.
- 정적 공개판 CSP를 적용한 테스트 서버에서도 문서 기능·내보내기 검사.

## 범위와 후속 단계

이번 범위는 계획서의 P0이다. 두 세트 비교 모드, 이름을 붙인 디자인 보관함, 35개 세부 유형의 추가 지면은 P1로 남는다. 원문을 작성하거나 완성 DOCX·PPTX·HWPX·PDF를 직접 만드는 기능은 포함하지 않는다.

실제 휴대전화의 브라우저·공유 시트와 처음 사용하는 사용자 5명의 사용성 평가는 별도 확인이 필요하다. 이번 검증의 모바일 결과는 브라우저의 모바일 뷰포트·터치 환경 검사다.

커밋·푸시·운영 배포는 수행하지 않았다. 기존 사용자 변경과 관련 없는 문서는 보존했다.
