# PromptDeck 배포 개인정보·법적 위험 검토

- 검토일: 2026-07-17
- 적용 가정: 대한민국에서 운영되는 웹 서비스
- 결론: **조건부 배포 가능**. 코드상 중대한 노출 경로는 보완했으나, 아래 `배포 전 필수 승인`을 완료하지 않으면 공개 배포하지 않는다.
- 주의: 이 문서는 기술·운영 관점의 컴플라이언스 점검이며 개별 사안에 대한 법률 자문을 대체하지 않는다.

## 1. 적용 기준

- 개인정보 처리방침 공개와 필수 기재사항: 개인정보 보호법 제30조 및 시행령 제31조
- 안전성 확보조치: 개인정보 보호법 제29조 및 개인정보의 안전성 확보조치 기준
- 국외 이전: 개인정보 보호법 제28조의8·제28조의9
- 정보주체 권리: 열람·정정·삭제·처리정지·동의 철회 및 회원 탈퇴
- 저작권·초상권·상표권: 사용자가 업로드하거나 생성하는 이미지 및 프롬프트
- 외부 AI·이미지·메일·광고 제공자 약관과 개인정보 처리조건

참고 원문: [국가법령정보센터 개인정보 보호법](https://www.law.go.kr/법령/개인정보보호법), [개인정보보호위원회 개인정보의 안전성 확보조치 기준](https://www.law.go.kr/행정규칙/개인정보의안전성확보조치기준)

## 2. 처리 데이터와 흐름

| 처리 항목 | 목적 | 저장 위치/전송 | 기본 보존 | 주요 통제 |
|---|---|---|---:|---|
| 이메일, 표시 이름, 역할, 비밀번호 해시 | 계정·권한 관리 | PromptDeck 서버 비공개 저장소 | 탈퇴 시까지 | scrypt 해시, HttpOnly 세션, 역할 통제 |
| 로그인·변경·생성 감사기록 | 보안 및 분쟁 대응 | `outputs/_private` | 365일 | 일반 웹 경로 차단, 주기 삭제 |
| 프롬프트와 업로드 이미지 | 이미지 생성 | 선택한 AI 제공자에게 전송 | 제공자 정책 + 서버 생성물 30일 | 매 요청 고지, 민감정보 패턴 차단, 크기·형식 검사 |
| 생성 이미지 | 결과 제공 | 사용자별 서버 경로 | 30일 | 소유자/관리자만 접근, 자동 삭제 |
| 단축 URL 원문 | QR 단축주소 제공 | PromptDeck 서버 비공개 저장소 | 30일 | 민감 쿼리·내부주소 차단, 만료 삭제 |
| 이메일 인증 정보 | 가입·이메일 변경 확인 | SMTP 및 비공개 저장소 | 인증 완료 또는 24시간 | 토큰 해시, TLS 기본 요구 |
| Unsplash 검색어·접속 정보 | 사진 검색 | Unsplash | 제공자 정책 | 명시 검색 시만 전송, 서버 프록시·출처 표시 |

보존기간은 환경변수로 단축할 수 있다. 백업에도 동일한 삭제정책을 별도로 적용해야 한다.

## 3. 위험 및 조치 상태

| 등급 | 점검 항목 | 상태 | 구현 또는 필요한 조치 |
|---|---|---|---|
| 높음 | 기본 관리자 계정·약한 비밀번호 | 조치 완료 | 운영 최초 계정은 환경변수로만 부트스트랩, 12자/3종 조합, 예시 비밀번호 거부 |
| 높음 | 인증 없이 설정·생성·관리 API 접근 | 조치 완료 | 로그인·관리자 역할·동일 출처·요청률 제한 적용 |
| 높음 | 브라우저 저장소의 세션 토큰/API 키 | 조치 완료 | HttpOnly/SameSite 쿠키 사용, 키는 서버 쓰기 전용·존재 여부만 노출 |
| 높음 | 사용자 생성물 및 내부 파일 공개 | 조치 완료 | 사용자별 소유권 검사, `_private`와 개발·백업·임시 경로 차단 |
| 높음 | 외부 AI로 개인정보 무고지 전송 | 조건부 조치 | 요청 전 고지·확인 및 패턴 차단. 운영자는 국외이전 법적 근거와 고지사항을 최종 확정해야 함 |
| 높음 | 탈퇴·열람·삭제 수단 부재 | 조치 완료 | 내 정보 내보내기, 비밀번호 확인 탈퇴, 생성물·세션·단축 URL 삭제 제공 |
| 중간 | 보존기한 없는 로그·생성물 | 조치 완료 | 생성물 30일, 감사기록 365일, 인증대기 24시간 기본 자동 정리 |
| 중간 | 외부 URL 가져오기를 통한 SSRF/추적 | 조치 완료 | 외부 이미지 가져오기 허용 목록을 비움; Unsplash는 제한된 서버 프록시만 사용 |
| 중간 | 외부 단축서비스에 URL 유출 | 조치 완료 | 외부 단축서비스 제거, 자체 만료형 단축주소로 대체 |
| 중간 | 저작권·초상권·상표권 분쟁 | 안내 조치 | 정책·신고 절차 제공. 운영자는 실제 신고 이메일과 처리 담당자를 지정해야 함 |
| 중간 | 광고 쿠키·행태정보 동의 | 배포 전 조건 | CMP 동의 신호 없이는 광고 스크립트가 로드되지 않음. 광고 사용 전 인증 CMP 구축 필요 |
| 중간 | CSP의 `unsafe-inline` | 잔여 위험 | 기존 인라인 스크립트 호환 때문에 유지. 차기 작업에서 nonce/hash 기반 CSP로 전환 권고 |
| 낮음 | 외부 폰트 호출로 IP 전송 | 조치 완료 | 외부 웹폰트 로딩 제거 |

## 4. 외부 제공자별 확인사항

- OpenAI API: API 데이터가 기본적으로 모델 학습에 사용되지 않지만, 일반적으로 남용 모니터링 로그가 최대 30일 보관될 수 있다는 공식 정책을 처리방침에 반영했다. 실제 계약·데이터 보존 옵션은 운영 계정에서 재확인한다. [OpenAI API 데이터 제어](https://platform.openai.com/docs/guides/your-data)
- Google Gemini API: 현재 약관상 18세 이상이며 전문·사업 목적 사용 조건이 있으므로 가입 및 호출 확인을 18세 이상으로 제한했다. Google 무료 서비스가 아닌 유료 서비스 전제 확인을 운영 환경변수로 요구한다. [Gemini API 추가 약관](https://ai.google.dev/gemini-api/terms)
- Unsplash: API 검색 결과 이미지는 서버 로컬 출력 폴더에 내려받아 제공하고, 사진가·Unsplash 표시와 다운로드 추적 호출을 적용했다. [Unsplash API 가이드라인](https://help.unsplash.com/en/articles/2511245-unsplash-api-guidelines)
- Pollinations: 개인정보·계약 조건을 운영자가 별도 확인하지 않는 한 운영 모드에서 활성화할 수 없다.
- Google 광고: EEA·영국·스위스 등에 개인화/비개인화 광고를 제공한다면 Google 인증 CMP가 필요하다. 현재는 동의 신호가 없으면 광고가 차단된다. [Google 인증 CMP 요구사항](https://support.google.com/adsense/answer/13554116)

## 5. 배포 전 필수 승인

1. 사업자/운영자명, 주소, 개인정보 보호책임자, 문의 이메일을 `.env`에 실제 정보로 입력한다.
2. HTTPS 리버스 프록시, Secure 쿠키, 신뢰 프록시 설정을 실제 도메인에서 검증한다.
3. OpenAI/Google/Unsplash/SMTP 등 실제 사용할 제공자만 선택하고 계약·국외 이전 국가·시점·방법·항목·목적·보유기간·거부방법을 법률 담당자가 확정한다.
4. 개인정보 처리방침·이용약관·AI 정책·저작권 정책의 운영자 정보를 검토하고 공개일을 기록한다.
5. 회원가입을 켤 경우 SMTP 발송·인증 만료·탈퇴·내보내기를 운영 환경에서 시험한다.
6. 광고를 사용할 경우 인증 CMP와 동의 철회 UI를 먼저 배포한다. 준비 전에는 광고를 비활성으로 유지한다.
7. 침해사고 대응 담당자, 신고·통지 절차, 접근권한 정기 검토, 백업 보존·삭제 정책을 내부 문서로 승인한다.
8. 아동 또는 일반 소비자를 대상으로 하거나 해외 이용자를 적극 유치한다면 별도 관할(GDPR, CCPA/CPRA 등) 검토를 받는다.

## 6. 운영 점검 주기

- 매월: 관리자 계정·권한·감사기록·실패 로그인 검토
- 분기: 외부 제공자 약관·모델·보존정책·국외 이전 고지 재검토
- 반기: 탈퇴·내보내기·자동 삭제 복구 테스트와 취약점 점검
- 변경 시: 수집 항목, 이용 목적, 제공자, 보존기간, 광고/분석 도구 변경 전에 영향평가 및 정책 개정

## 7. 최종 판정

기술적 차단과 이용자 권리 기능은 공개 배포에 필요한 수준으로 보완되었다. 다만 실제 사업자 정보, 제공자 계약, 국외 이전의 법적 근거, HTTPS 운영 검증, 내부 대응 절차는 코드가 대신 확정할 수 없다. 위 필수 승인을 모두 완료한 뒤에만 운영 배포한다.
