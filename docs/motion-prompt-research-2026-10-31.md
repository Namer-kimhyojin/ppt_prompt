# 모션 애니메이션 프롬프트 기능: 조사와 구현 근거

확인일: 2026-10-31. 적용 범위: 신규 `영상·모션 → 모션 애니메이션` 도구. 외부 API 호출 없이 브라우저에서 요청문을 구성한다.

## 현재 방식: 구성 방향을 전달하고 AI에게 상세 기획 받기

사용자 요청에 따라 ‘용도·원문·시청 대상·스타일 → 기획 요청문 복사’의 단일 기능으로 정리했다. 요청문 종류 4개, AI 대상·코드 산출물 선택, 수정 입력과 직접 장면 편집을 제거했다. Claude·GPT에 공통으로 전달할 요청문 1개만 제공한다. 고정된 장면표나 균등한 초 배분을 넣지 않으며, AI가 구성안 3개를 비교·추천하고 전체 길이, 장면 수와 순서, 타임스토리·콘티·자막·대본·음향을 직접 제안하도록 요청한다. 희망 길이를 비워 두면 AI가 적정 길이를 추천한다.

진행 순서는 PC·모바일 모두 `1 구성 방향 → 2 스타일 선택 → 3 요청문 복사`다. 첫 화면은 구성 방향이며, 다음/이전 버튼과 단계 탐색으로 이동한다. 2단계는 스타일 목록과 미리보기, 3단계는 선택 요약과 요청문을 보여 준다. 모바일 하단 액션도 처음에는 ‘다음: 스타일 선택’, 다음에는 ‘다음: 요청문 복사’, 마지막에는 ‘기획 요청문 복사’로 바뀐다. 단계 이동은 입력과 스타일을 변경하지 않는다.

[사용자 참조 사이트 Lemo-Opuscar](https://lemomo-ai.github.io/lemo-opuscar/)의 11개 계열·66개 스타일을 조사했다. 영상 용도 18개와 시각 스타일을 분리하고, 스타일마다 재질·화면·움직임의 한국어 방향을 작성했다. 참고 작품의 줄거리·인물·장면 순서·문구는 사용자의 기획 조건으로 가져오지 않는다. ‘AI 추천’을 고르면 서로 다른 스타일 3안을 비교하도록 요청한다.

원본 스틸은 LemoLab의 명시된 CC BY 4.0 조건에 따라 출처·저작자·라이선스를 표시하고 이미지 파일 변경 없이 사용한다. 원본 영상과 음성은 포함하지 않으며 참고영상 링크만 제공한다. 스냅샷 커밋은 `f17136060781a0068a7951245a3aa7835a7230de`, 66개 이미지와 각 STYLE.md의 해시는 `assets/motion-style-previews/manifest.json`에 기록했다. 한국어 스타일 설명과 요청문은 PromptDeck에서 작성했다.

기존 v1·v2의 제목·원문·스타일과 장면 자료는 보존해 v3로 이전한다. 과거의 장면 자료와 제작·수정 설정은 저장 데이터에 보관하되 기획 요청문에는 전달하지 않는다. 장면 수·시간 배분을 포함한 상세 기획은 AI에게 맡긴다. 아래 최초 조사·구현의 제작·수정 관련 내용은 이전 구현의 기록이다.

v2 검증: 66개 스타일의 이미지 디코딩·출처 해시·요청문 반영, 기본 요청문에 고정 장면표가 없는 점, 희망 길이 지정과 AI 위임, 직접 장면표의 명시적 포함, v1 저장 자료의 UI 이전·보관을 확인했다. 모션 전용 검사·전체 smoke test·공개 접근 검사가 통과했다. 상세 기획은 사용자가 요청문을 외부 AI에 전달해 받으며, 이 도구 안에서 AI 응답을 생성하는 기능은 추가하지 않았다.

## 최초 구현 범위와 검증 기록

- 18개 자체 SVG 샘플 이미지와 재생 가능한 움직임 예시. 외부 템플릿·이미지·네트워크에 의존하지 않음.
- Claude/GPT 대상, HTML·Remotion·기획서 산출물, 제작 요청/장면별 영상/스토리보드/수정 요청 출력.
- 장면 추가·삭제·정렬, 길이 비례 배분, 참조 이미지·자막·대사, 화면비·fps·카메라·음향·루프.
- 현재 출력 복사·UTF-8 TXT 저장, 로컬 자동 저장·복원, 초기화 되돌리기, 모바일 작업 화면 전환.
- 생성되는 것은 제작 프롬프트다. 샘플 재생은 입력 내용으로 렌더링한 완성 영상이 아니며 MP4 제작·검증은 별도 제작 도구에서 수행한다.
- 회귀 검증 명령: `npm run motion:test`, `node scripts/smoke-test.mjs`, 변경 JS의 `node --check`, `git diff --check -- index.html src styles`.

2026-10-31 검증 결과: 신규 모션 테스트, 전체 smoke test, 공개 접근 smoke test, 변경 JS 문법 검사, diff 공백 검사, UTF-8/BOM 검사가 모두 통과했다. 신규 테스트에서는 1440·1024·810·720·390·360px, 라이트·다크 테마, 모션 감소 설정을 확인했다. 홈페이지·전체 기능 안내에서 새 탭으로 이동하는 경로와 기존 지도·부속 양식의 하위 탭 전환도 확인했다. 실제 Claude/GPT 또는 영상 생성 서비스에서 결과 영상을 렌더링하는 검증은 수행 범위에 포함하지 않는다.
