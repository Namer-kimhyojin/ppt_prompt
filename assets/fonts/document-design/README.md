# Document preview fonts

Retrieved from the official Google Fonts repository on 2026-09-08:

- https://github.com/google/fonts/tree/main/ofl/notosanskr
- https://github.com/google/fonts/tree/main/ofl/notoserifkr

Variable TTF files were losslessly converted to WOFF2 with FontTools. Glyph outlines and names were not modified. Both fonts are redistributed with their original SIL Open Font License files. Preview code waits for the fonts to load before exporting PNGs.
